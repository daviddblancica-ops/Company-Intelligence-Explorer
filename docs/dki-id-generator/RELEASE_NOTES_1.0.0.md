# DKI ID Generator 1.0.0

První publikované vydání doprovodného Windows nástroje pro Company Intelligence Explorer.

## Balíčky

- `DKI-ID-Generator-Setup.exe` pro běžnou instalaci
- `DKI-ID-Generator-x64.msi` pro spravované nasazení
- `SHA256SUMS.txt` pro ověření stažených souborů

## Důležité upozornění

Instalační balíčky této verze zatím nejsou digitálně podepsané. Windows může zobrazit
varování SmartScreen. Před instalací ověřte SHA-256 podle přiloženého souboru.

Generátor pracuje lokálně. Hesla, vytvořené identifikátory ani obsah šifrovaného
trezoru se automaticky neodesílají do Company Intelligence Exploreru.
