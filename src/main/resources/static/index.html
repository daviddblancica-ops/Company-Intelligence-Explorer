Firemni data bez chaosu

Naimportuj subjekt z ARES podle ICO, sjednot data a hledej v nich pres jednoduche rozhrani.

Server bezi API je dostupne na portu 8081.

Vstup

  • CSV nebo JSON soubory s daty o firmach
  • informace o lidech
  • role lidi ve firmach

Uvnitř

  • kontrola a sjednoceni dat
  • ulozeni vazeb mezi lidmi a firmami
  • historie zmen a priprava pro hledani

Výstup

  • vyhledavani a detail firmy
  • prehled napojenych lidi
  • historie zmen a watchlist

Jednoducha analogie

Kdybys mel velkou skrin plnou sanonu o firmach, projekt dela ctyri veci:

  1. vezme rozhazene papiry a spravne je zaradi
  2. nadepise je jednotne, aby se daly najit
  3. doplni karticku s historii zmen
  4. prida rychly rejstrik pro hledani podle jmena nebo identifikace

  • Elasticsearch

  • REST API
  • monolithic backend
