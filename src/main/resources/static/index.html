Company Intelligence Explorer

Backendova aplikace pro import, sjednoceni, historii zmen a rychle hledani firemnich dat.

Import dat

CSV a JSON vstupy pro zalozeni nebo aktualizaci firem.

Sjednoceni dat

Normalizace nazvu pro spolehlive vyhledavani.

Historie zmen

U kazde firmy se ukladaji udalosti vytvoreni a uprav.

Vyhledavani firem

Zadej nazev nebo identifikaci firmy a spust hledani.
